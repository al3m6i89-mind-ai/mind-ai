# قارئ الملفات والصور — المرحلة الأولى

تطبيق محادثة بالذكاء الاصطناعي يعمل على جهازك مجاناً. هذه النسخة هي **المرحلة الأولى**: واجهة المحادثة الكاملة وخادم محلي يحفظ المحادثات والملفات، مع ردود حقيقية من نموذج ذكاء اصطناعي مجاني يعمل على جهازك (Ollama).

## ما الذي يعمل في هذه النسخة

- واجهة محادثة بالعربية (من اليمين لليسار) والإنجليزية، مع وضع ليلي ونهاري، ومناسبة للهاتف.
- شريط إرسال ثابت: مربع «اسأل عن ملفاتك...» بداخله زر إرفاق ملف وزر إرفاق صورة، وزر إرسال مستقل خارجه.
- ردود مباشرة (حرفاً بحرف) من النموذج، مع زر إيقاف، وزر «إعادة المحاولة» عند الخطأ.
- محادثات متعددة: إنشاء، إعادة تسمية، حذف، بحث في العناوين والرسائل وأسماء الملفات. كل شيء محفوظ بعد إغلاق التطبيق.
- رفع الملفات والصور مع شريط تقدم: PDF وWord وPowerPoint وExcel وTXT وCSV وMarkdown وJPG وPNG وWEBP. يظهر لكل ملف اسمه ونوعه وحجمه وحالته، مع فتحه أو حذفه.
- رفض الملفات غير المدعومة أو المزيفة (مثلاً ملف exe أُعيدت تسميته إلى pdf) برسالة واضحة.
- السحب والإفلات ولصق الصور.

## ما لم يُنفَّذ بعد (بصراحة)

- **تحليل محتوى الملفات والصور غير مفعّل بعد.** الملفات تُرفع وتُحفظ، والمساعد يعرف أسماءها فقط، وقد طُلب منه أن يقول ذلك بوضوح بدل التخمين. التحليل يأتي في المراحل 4 إلى 7.
- لا توجد حسابات مستخدمين بعد (المرحلة الثانية)، لذلك لا تجعل التطبيق متاحاً على الشبكة إلا لنفسك.
- الاشتراكات والحدود تأتي مع مرحلة الحسابات.

## التثبيت (مرة واحدة)

1. ثبّت **Python 3.10 أو أحدث** من https://www.python.org/downloads/
   في Windows فعّل خيار «Add Python to PATH» أثناء التثبيت.
2. ثبّت **Ollama** من https://ollama.com/download وشغّله.
3. نزّل النموذج المجاني (حوالي 4.7 جيجابايت، مرة واحدة). افتح الطرفية (Terminal أو PowerShell) واكتب:

   ```
   ollama pull qwen2.5:7b
   ```

   إذا كانت ذاكرة جهازك 8 جيجابايت أو أقل، استخدم نموذجاً أصغر:

   ```
   ollama pull qwen2.5:3b
   ```

   ثم افتح ملف `.env` (يُنشأ تلقائياً عند أول تشغيل) وغيّر السطر إلى `OLLAMA_MODEL=qwen2.5:3b`.

## التشغيل

- **Windows:** انقر مرتين على `start.bat`.
- **Mac / Linux:** افتح الطرفية داخل المجلد واكتب `./start.sh`

ثم افتح المتصفح على: **http://127.0.0.1:8000**

أسفل القائمة الجانبية يظهر حال الاتصال بالنموذج. إذا كان أحمر فالرسالة بجانبه تشرح السبب وما تفعله.

## خيار اختياري: Claude بدل النموذج المحلي

النموذج المحلي مجاني لكنه أقل دقة. لاستخدام Claude (مدفوع حسب الاستخدام) ضع في ملف `.env`:

```
AI_PROVIDER=claude
ANTHROPIC_API_KEY=مفتاحك
```

المفتاح يبقى في الخادم على جهازك ولا يُرسل إلى المتصفح.

## أين تُحفظ البيانات

كل المحادثات والملفات في مجلد `data/` داخل مجلد التطبيق. حذف محادثة يحذف ملفاتها نهائياً من هذا المجلد.

## الاختبارات

```
pip install pytest
python -m pytest tests/test_api.py      # اختبارات الخادم (9 اختبارات)
node tests/e2e_ui.js <url> <fixtures> <shots>   # اختبار الواجهة في متصفح حقيقي (يحتاج Playwright)
```

الاختبارات تستخدم خادماً بديلاً يحاكي Ollama (`tests/fake_ollama.py`) حتى تعمل دون تنزيل نموذج.
